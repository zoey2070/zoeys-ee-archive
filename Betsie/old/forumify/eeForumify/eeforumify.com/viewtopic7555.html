Rules for the graphics suggestions sub-forum.

Welcome to the new sub-forum made specifically for all the creative guys out there who like to make blocks and smilies! I felt that it was neccessary to split the game suggestions from the graphical suggestions as the other sub-forum is just getting flooded with creativity, so to speak.

Anyhow, the rules are:

1. Only graphical suggestions made specifically for this game are allowed to be posted here. This includes, smilies, blocks and anything else you guys can come up with.

2. Off-topic posts will be deleted.

3. Posts regarding where to get certain software illegally (such as Photoshop) will result in a removed post and a warning (followed by banning if you break this rule again.)

Hope you guys have some great stuff to show us. Now fire away!
