Sped up forum load times

Hey guys!

I just sped up forum load times again. For those interested, Forumify's code now implicitly flushes the output buffer. In english, that means that whenever something is output it is immediately sent to the user's browser instead of waiting for the whole page to load.

This means that in the event the server is really slow, it won't have quite as dramatic of an effect, and pages will seem to load faster in general.

Enjoy!
