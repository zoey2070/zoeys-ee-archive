How the Action Blocks Work:
Key - When you select it in the GUI, a box will come up. You choose the Target Door's ID here.
Door - When you select it in the GUI, a box will come up. You choose the Door's ID here.
If the Key has an ID of 5, it will open a door with an ID of 5.

Card Pack

Pressure Blocks

BLOCK 1: The pressure plate, you set how many smileys have to stand on it for the door/gate to open. (Max. 10)
BLOCK 2: The Door. Once X Smileys stand on the pressure plate block this will open for 4 seconds.
BLOCK 3: The Gate. Once X Smileys stand on the pressure plate block this will shut for 4 seconds.
