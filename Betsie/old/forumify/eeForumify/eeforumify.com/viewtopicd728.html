I'd like warp doors, that teleport you to a different area of the same level, so you could make a building engine without having a scripting feature.
Also, I'd like a way to make blocks, via a special panel.
It could have the features of Scratch (scratch.mit.edu), just not using the block engine. Here are the features I want in the special panel:
- Open it via a new UI drop-up-opener-button called "Modify Blocks",
- A simple scripting area to script in,
- Block painter, allows you to paint a block, and
- Costume switcher, allows you to have different costumes and paint them via Block painter.
These ideas shouldn't be in the shop, for the reasons:
- Anyone will want to make their own block, and
- If it doesn't cost anything in the shop, then no more updates will have to be made, because the commands should be almost endless!
How I plan the syntax:
It'd either be a block engine from Scratch, or it should be like:

[set variable <prop variable used?> to <true>]
[smiley move "1" steps with speed of "1"]
[smiley if <<(blue coins) is more than (prop variable)> then {
[smiley wear crown]
[/if]
[variables]
[system]
(blue coins)
(coins)
(keys)
(prop variable)
<key activated?>
<room-owner only?>
<prop variable used?>
[/system]
[script vars]
<true>
<false>
<neutral>
[/script vars]
[/variables]

If you need more exams of script, I am more than happy to post an example!
