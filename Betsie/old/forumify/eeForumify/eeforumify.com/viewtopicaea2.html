Re: Ideas for bricks

alright, i have a couple idea's for blocks:
check point block: if touched, ti would activate and if you left the level and came back to it whenever you wish, you'll restart at that check point block you touched.
finish line block (in junction with check point): if touched disables all check points and you'll start back at a spawn point if you enter the level again, these two blocks are useful together.
all basic colors of basic blocks should also be metal colors: it would be more variety if we had more colors of metal blocks.
keys and gates: more colors: yellow, cyan, and purple, we would be able to make more key puzzles without using the same doors, leading to errors in levels at some point.
fan block: blows wind in whichever direction you choose it to, if it blows sideways it will push the player that way, making it harder to move toward the block then it is to go the direction of the wind, if the block is set to downward, jumping becomes harder and you won't jump as high, if set to upward, would cause jumps to be higher and falls to be slower.
teleport block: would allow you to go from block to block, you set the number (1-9) which shows on the block, when you touch one you go to the other respective numbered block, useful for any type of level.
more colors for basic and brick blocks: more color would mean better art levels, not much use here though...
energy block: looks like an ordinary block, but when touched gives a random amount of energy to the user, can only be set by admin(s)!
gem block: can only be set by admins and will give a random amount of gems to the user, unlike the energy block, once touched it's gone for good! the gem block looks like a gem though.
blue/light blue crown: just another crown sprite, you can't have it and the yellow crown at the same time.
allow more then one person to have the crown: so people can mark who won the level, rather who beat it recently.
well, that's all i have to say.
