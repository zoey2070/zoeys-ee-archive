Rules Clarification and other stuff

New rules:

We are now banning any accounts found to be using any sort of web proxy.

Auto-play youtube videos are now STRICTLY forbidden anywhere on the forums and will result in a warning for the poster.  Youtube videos at all in signatures are also forbidden and will result in a warning.

Rules clarifications:
Gravedigging:

Reviving a thread that still needs an answer or is still relevant is alright and does not count as gravedigging, no matter how old.  However, reviving a thread that has already been resolved, or wasn't even a question (for example, an announcement, or a thread like "How do I jump in EE?", which someone already answered) is gravedigging and will result in a warning.  If you do revive a thread, make sure your reply is relevant and useful to the OP (original/first post).

Double/Multi Posting:

Posting twice, or more than twice in a row will result in a warning.  However, doubleposting with more than 1 week between the two posts, as long as it is not gravedigging, is valid, IF you are bumping a thread.  Also, doubleposting or more is valid if it is an extension of the OP.

Other languages:

If the OP is in English, all replies should be in English.  If the OP is in Russian, all replies should be in Russian, etc.
Abuse of this rule will result in a warning.  The staff will determine what is considered abuse.
