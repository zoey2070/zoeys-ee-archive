EE Art - Tutorials (Many pictures!)

Tutorials wrote:

Rock
Lava
Tree


Rock wrote:

1. Start out with a basic shape


2. Add some shading


3. Add ridges and make them a little brighter on the top or bottom depending on your light source


4. Smooth our the edges using sort of dark blocks to dark blocks depending on how much space is on the lines

Lava wrote:

1. Start out with the base background (lightest colored lava)


2. Add a slightly orange color (Christmas 2012) in the flow of the lava


3. Add the medium color (Lava background) in the flow of the lava next to the Christmas 2012 background


Tree wrote:

1. Start with the base of the tree (crate block in factory pack). Also keep in mind that trees aren't perfectly straight.


2. Add the branches in the trees. Make sure that there are little branches on the bigger main branches to make it more realistic.


3. Use a light green color and make a bush thing around your branches (but they should still be visible)


4. Use a darker color to make lines like veins (I used green brick) and add a little shading on it (I used green basic)


5. Add some sloppy shading (trees aren't perfectly round) and your done!
