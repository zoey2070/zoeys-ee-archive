Re: [Solved] Simultaneous connection limiting

I have resolved this issue, and I'll post the solution in case anyone else has this issue.

The issue stemmed from an architecture problem. My application was sending n bots to connect all at the exact same time, which caused some to not connect (alas, as PlayerIO errors were silenced in a try block).

Solution: wait about 3 seconds before allowing another client to log on.
