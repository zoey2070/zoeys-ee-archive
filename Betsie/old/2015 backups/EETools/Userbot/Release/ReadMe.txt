UserBot by BuzzerBee -- ReadMe

UserBot v. 2.0.0 (updated June 7th, 2012, 04:03 pm CST)

UserBot allows users to place blocks that normally only owners could place.

~Basic Help:~

Logging in:

To log in, first enter the email that you use to log on to your Everybody Edits account in the "Email:" field.

Next, enter the password for the account that goes along with the email used in the "Password:" field.

Then enter the world ID to the desired level that you want the bot to enter in the "World ID:" field. You can find the world ID by clicking the "Share Level" button on the bottom left of the screen when you're in the level. After "/games/" you should see a "PW" or a "BW" followed by a bunch of random characters. Copy it, starting with the "PW"/"BW" and paste it into the "World ID:" field in the bot.

Lastly, press the "Connect!" button, and the bot should enter the desired level as the desired user!

Note: To connect to the level, you must be the owner. If you are not the owner, the bot will disconnect and give you an error message in the "Information:" box.
Note: To connect to the level, there must be a player already in the world.

Disconnecting:

Simply press the "Disconnect" button (if you are already logged in) to disconnect from EE.

Commands:

If you are an admin, you can say these commands in EE Chat to change certain things:

*help - Links you to the official UserBot Help and Instructions website.
*portal (direction) (id) (exit) - Changes the direction, id, and exit of the future portals placed by the bot.
*coindoor (amount needed) - changes the amount needed to pass through the coin door of the future coin doors placed by the bot.

How to place blocks:

Place these backgrounds, and it will be replaced by an Owner-Only block by the bot.

Gray Basic BG - Bot will replace with spawn.
Blue Basic BG - Bot will replace with solid secret block.
Purple Basic BG - Bot will replace with passable secret block.
Yellowish Basic BG - Bot will replace with coindoor with the specified amount in *coindoor (amount needed)
Light Blue Basic BG - Bot will replace with portal with specified parameters.
Green Basic BG - Bot will replace with "completed level" block.

Note: The Bot can only place as many Owner Blocks as you own.

~Parameter Help:~

Portals:

When you type "*portal" in EE, you must put 3 numbers after it.
The first number is the Direction of the portal.
1 = left, 2 = up, 3 = right, 4 = down, 100 = invisible
The second number is the portal id. (What number the portal is)
The third number is the portal exit. (What portal id this portal leads to)

Whenever you use the *portal command, it will affect the new blocks placed with light blue basic background.

Example:
*portal 4 1 2
(that would make a portal facing down, with an ID of 1, that would lead me to a portal with the ID of 2.)

Coindoors:

When you type "*coindoor" in EE, you must put 1 number after it.
The number you must put is the amount of coins needed to pass through the Coin Door.
If you use a 0, it will be an "open coin door", which means no coins are required to pass through it.

Whenever you use the *coindoor command, it will affect all the new blocks placed with the yellowish basic background.

Example:
*coindoor 3
(that would make a coin door that requires the player to have 3 coins to pass through.)

~Admin Help:~

Adding an admin:

To add an admin, type their username in !all lowercase! letters in the "Admins:" field. Then press enter if you would like to add a new admin.


Removing an admin:

To remove an admin, erase their username from the "Admin:" field.

Other:

There must be a new line between each admin, and all admins' username must be written in lowercase letters.

To create a permanent admin, write their username in the admins.txt file located in this folder.
(Note: Permanent admins may not work)

~Error Help:~

Basic help:

If there is an error with logging in, a Message Box will pop up stating the error, and it will also appear in the "Information:" field.

The first words error should be self explanatory, and the rest of it should be a more detailed description of the error.

Common errors:

"The username does not exist" - The email used is wrong and does not exist.
"Wrong password" - The entered password is incorrect, it does not match the email.
"Room does not exist" - The World ID is wrong, or nobody is currently in that world.
