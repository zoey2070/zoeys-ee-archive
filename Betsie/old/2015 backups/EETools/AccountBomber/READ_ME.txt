HOW TO USE:

To use Account Bomber, you must create a text file that has a list of two things:
1) The accounts' email addresses
2) The account's passwords

To do this, you must separate the email and password with a space, and each new account with a new line.

For example:

pythonpython@gmail.com 123456789
boilingbunny@gmail.com 123456789

(Within the folder, there is already a file with a list of accounts for you!)

When you have a list of accounts, open the application.

To choose the file you would like to select, click the "Browse" button and open the desired file.
Next, you have the option to send all the accounts in the file, or just send a select amount.

If you choose to send a custom amount of accounts, you will have the option to send them randomly.
This means that instead of going with the order the accounts are written in the file, it will randomly select the accounts.

Next, enter the world ID of the level you would like to be bombed. This can be found at the end of the level's URL, starting with a "PW" or a "BW".

For example:

The world ID of the URL
http://everybodyedits.com/games/PWmsndD1k4bkI
Would be
PWmsndD1k4bkI

Finally, when all of your settings are ready, click the big button with the bomb!

This will start preparing the accounts to connect.

When you're ready to remove the bombed accounts, click on the big button with the X. This will disconnect all of your accounts!
~~~
